# Internationalization (i18n)

SOLO. UI and exercise content support **English (default)**, Dutch, German, and French.

## Switch language

Settings → **Language**. Preference is stored in `localStorage` as `solo-locale`.

## Contribute a new language

1. Add an entry to `src/i18n/registry.ts` (`code`, `nativeName`, `wgerId`, `speechTags`).
2. Copy `src/i18n/locales/en/*.json` to `src/i18n/locales/<code>/` and translate.
3. Register the new locale resources in `src/i18n/index.ts`.
4. No call-site changes if keys stay stable; missing keys fall back to English.

Namespaces: `common`, `nav`, `settings`, `session`, `workouts`, `wger`, `locker`, `coach`, `home`, `history`, `themes`, `about`, `labs`, `tv`.

## Exercise descriptions

Imported Wger exercises store:

- `sourceDescription` / `sourceLang` — original text
- `descriptionByLocale` — per-locale resolved text (native Wger or machine translation)
- `description` — last resolved string for the active locale

When the app language changes, opening exercise info re-resolves via Wger (if `externalId`) or MyMemory from `sourceDescription` when auto-translate is on.

See [i18n-plan.md](./i18n-plan.md) for the full architecture.
